# Neural Lab

Open `index.html` locally in a modern browser (download the raw file first). The 3D constellation uses perspective projection on Canvas; the game supports keyboard and on-screen controls. No dependencies or backend are required.

To publish: repository Settings → Pages → Deploy from a branch → main → /docs → Save. GitHub will display the published URL after deployment. Add that verified URL to the profile README. Until Pages is enabled, use the local HTML file. This folder has not been deployed automatically.
