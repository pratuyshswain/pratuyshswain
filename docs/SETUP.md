# Contour Survey

Open [the browser edition](https://raw.githack.com/pratuyshswain/pratuyshswain/main/docs/index.html), or download `index.html` and open it locally. The game is a self-contained Canvas application with no build step or external dependencies.

Drag horizontally or use the rotation buttons to inspect each landscape. Orbit starts and pauses continuous rotation. All game controls work by keyboard. Field readings provide the same elevation information in text.

For GitHub Pages hosting, select **Settings → Pages → Deploy from a branch → main → /docs**. The browser edition linked above uses a preview of the public repository file.
